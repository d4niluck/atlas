## Пространство для мыслей

Информация редко складывается в идеальный список папок. Atlas позволяет разместить заметки, документы и изображения на свободной доске, соединить их и собрать в группы. Откройте карточку, чтобы прочитать заметку или посмотреть файл, не теряя структуру целого.

Каждому пространству соответствует отдельная доска. Можно вести несколько пространств и переключаться между ними во вкладках.

## Возможности

**Доска и заметки**
- Располагайте карточки на доске, связывайте их стрелками и объединяйте в группы.
- Пишите заметки в Markdown и переключайтесь между чтением и редактированием.
- Добавляйте файлы и изображения, просматривайте поддерживаемые форматы внутри приложения.
- Отменяйте действия и восстанавливайте недавно удалённые объекты.

**Поиск по содержимому**
- Ищите по словам, смыслу или используйте оба режима одновременно.
- Выделяйте карточки на доске, чтобы ограничить поиск выбранными объектами.
- Переходите из результатов к исходной заметке или документу.
- Задавайте вопросы в умном поиске: ответ формируется по найденным фрагментам, а источники и результаты доступны для просмотра.
- На macOS ищите из строки меню, не переключаясь в основное окно Atlas.

**Данные остаются у вас**
- Работайте локально без аккаунта и облачного поиска. Для первоначальной загрузки моделей нужен интернет.
- Оригиналы добавленных файлов сохраняются в пространстве; их можно выгрузить для работы вне Atlas.
- Копируйте пространства, работайте с ними на внешнем носителе и при необходимости защищайте паролем.

## Как работает поиск

| Режим | Когда полезен |
|---|---|
| **По словам** | Вы помните конкретные слова или название. Поиск доступен без модели и учитывает опечатки. |
| **По смыслу** | Вы помните идею, но не точную формулировку. |
| **Умный поиск** | Вы хотите получить ответ по найденным фрагментам. Выберите локальную LLM и при необходимости откройте источники. |

Индексируются заметки и текст, извлечённый из **Markdown, TXT, PDF и Word**. Файлы других форматов можно искать по названию или добавленному описанию. Изображения могут участвовать в смысловом поиске при включённой модели для изображений. Для файлов, которые не содержат доступного текста, можно добавить описание вручную.

Модели скачиваются отдельно и работают локально. Семантический и умный поиск требуют соответствующих загруженных моделей; лексический поиск работает без них. Доступные устройства и модели выбираются в настройках поиска. При формировании ответа текст появляется постепенно, генерацию можно остановить.

## Поддержка платформ
**macOS — основная платформа разработки.** Новые изменения сначала готовятся и проверяются на ней, затем переносятся и проверяются на Ubuntu. Поддержка Windows отложена; готовой Windows-версии нет.

Обозначения: **проверено** — функция проверена в указанных условиях; **частично** — проверена не целиком или на более старой версии; **не проверено** — подтверждения нет.

Для выпуска **0.0.36** изменения интерфейса из снимка `2f67428` проверены на macOS Apple Silicon: прошли 165 автоматических проверок интерфейса и отдельные проверки выборочной заливки групп в WKWebView. На Ubuntu 26.04 x86-64 пользователь проверил предыдущую сборку на основе `b3a9524`; перенос индекса дополнительно проверен на отдельной копии пространства на физической флешке. Выборочная заливка и весь выпуск 0.0.36 на Ubuntu ещё не проверены. Чистая установка macOS и Intel Mac не проверены. Проверка функции на одной платформе не подтверждает её работу на другой.

| Функция | macOS | Ubuntu |
|---|---|---|
| Ускорение ответа n-gram | Частично: генерация на Metal проверена на трёх моделях; приложение целиком не проверено | Недоступно: поддерживается только Metal |
| Доска, заметки и файлы | Проверено на Apple Silicon; последняя заливка групп дополнительно проверена в WKWebView на синтетической доске | Частично: пользователь проверил предыдущую сборку на основе `b3a9524`; выборочная заливка и выпуск 0.0.36 не проверены |
| Поиск по словам и смыслу, модели Q8 и BF16 | Проверено на Apple Silicon | Частично: лексический поиск и переключение Q8 → BF16 → Q8 на 0.0.35 проверены на изолированных данных |
| Поиск по изображениям | Проверено на Apple Silicon | Частично: смысловой поиск изображения на 0.0.35 проверен на изолированных данных |
| Умный поиск с Gemma E2B/E4B | Проверено на Apple Silicon | Частично: E2B и E4B на 0.0.35 проверены на изолированных данных |
| Поток ответа и остановка | Проверено на Apple Silicon | Частично: Ubuntu ARM64 с имитацией модели; на реальном x86-64 ПК и в интерфейсе не проверено |
| Умный поиск с Nemotron | Проверено на Mac | Не проверено |
| Обычные и защищённые пространства | Проверено на Apple Silicon | Частично: перенос на изолированных данных и переход защищённого пространства с 0.0.29 проверены; внутреннее состояние его индекса не проверено |
| Перенос пространств и внешний носитель | Частично: проверено копирование пространства для тестов; не все сценарии между компьютерами проверены | Частично: на отдельной копии пространства проверены подключение физической флешки и поиск в предыдущей сборке на основе `b3a9524`; выпуск 0.0.36 и физическое извлечение не проверены |
| Перенос готового индекса между CPU и MPS | Частично: подготовлена копия для проверки на Ubuntu; не все сценарии проверены | Частично: поиск на CPU по копии индекса с Mac проверен на флешке в сборке на основе `b3a9524`; выпуск 0.0.36 и все сочетания моделей не проверены |
| Счётчик памяти | Частично: приблизительная сумма памяти процессов; наблюдение на другом Mac не выяснено | Не проверено достаточно для подтверждения |
| Быстрый поиск в строке меню | Частично: поиск и переход к заметке проверены на Apple Silicon; формулы последней версии проверены автоматически | Недоступен: функция только для macOS |
| Сборка и установка | Сборка и локальный запуск предрелизного снимка на Apple Silicon; чистый Mac и Intel не проверены | Предыдущая сборка на основе `b3a9524` установлена и проверена пользователем; сборка и чистая установка 0.0.36 ещё не проверены |

При добавлении или изменении функций обновляйте эту таблицу и отмечайте платформу как проверенную только после соответствующей проверки.

## Сборка
Atlas находится на раннем этапе разработки. Готовые общедоступные загрузки пока не заявлены; модели и рабочие пространства хранятся отдельно от приложения.

- **macOS Apple Silicon:** [инструкция по локальной сборке](docs/BUILD.md). Нужны Rust, Node.js и подготовленные локальные зависимости, включая llama и PDFium. Сборка использует зафиксированный коммит Git.
- **Ubuntu x86-64:** [сборка Ubuntu-пакета с Mac через Docker](scripts/linux-release/README.md). Инструкция описывает необходимые системные библиотеки и ограничения протестированной конфигурации.

## О проекте
Atlas назван в честь Атланта, который держал небесный свод. Проект находится в разработке: поведение и поддержка платформ могут меняться.

## Ветки
- `master` — основная версия для macOS и Ubuntu.
- `develop` — текущая разработка основной версии.
- `windows` — отдельные экспериментальные наработки для Windows; готовой версии нет.
