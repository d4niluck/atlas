# Atlas

Atlas — локальное приложение для хранения заметок и файлов на доске и поиска по ним. Основная платформа разработки — **macOS**: новые функции сначала разрабатываются и проверяются на ней. Затем их необходимо собрать и проверить на Linux и Windows; наличие функции в macOS не означает её готовности на других системах.

## Поддержка платформ

Таблица — журнал подтверждённой поддержки. Обновляйте её вместе с изменениями: указывайте версию и условия проверки, а новые или изменённые функции отмечайте как непроверенные на каждой платформе до фактической проверки.

Обозначения: **проверено** — функция проверена в указанных условиях; **частично** — проверена не целиком или на более старой версии; **не проверено** — подтверждения нет; **не готово** — рабочая версия для платформы ещё не реализована.

Последняя проверенная основная версия на Linux — **0.0.29**, Ubuntu 26.04 x86-64. Для macOS проверки проведены на Apple Silicon; чистая установка и Intel Mac не проверены. Готовой версии для Windows пока нет.

| Функция | macOS | Linux | Windows |
|---|---|---|---|
| Доска, заметки и файлы | Проверено на Apple Silicon | Частично: 0.0.29, Ubuntu; не все действия в интерфейсе проверены | Не готово |
| Лексический и смысловой поиск, модели Q8 и BF16 | Проверено на Apple Silicon | Частично: проверено на 0.0.29; текущая версия не проверена | Не готово |
| Поиск по изображениям | Проверено на Apple Silicon | Частично: проверено на 0.0.29; текущая версия не проверена | Не готово |
| Умный поиск с Gemma E2B/E4B | Проверено на Apple Silicon | Частично: проверено на 0.0.29; текущая версия не проверена | Не готово |
| Поток ответа и остановка | Проверено на Apple Silicon | Частично: Ubuntu ARM64 с имитацией модели; на реальном x86-64 ПК и в интерфейсе не проверено | Не готово |
| Умный поиск с Nemotron | Проверено на Mac; пользователь подтвердил работу | Не проверено | Не готово |
| Обычные и защищённые пространства | Проверено на Apple Silicon | Частично: проверено на 0.0.29; текущая версия не проверена | Не готово |
| Перенос пространств и флешка | Частично: разные физические компьютеры ещё не проверены | Частично: ext4 и FAT32 на 0.0.29; физическое извлечение не проверено | Не готово |
| Перенос готового индекса между CPU и MPS | Частично: проверен перенос из 0.0.30 на одном Mac, включая защищённые пространства | Не проверено | Не готово |
| Счётчик памяти | Частично: приблизительная сумма памяти процессов; наблюдение на другом Mac не выяснено | Не проверено достаточно для подтверждения | Не готово |
| Сборка и установка | Сборка и локальный запуск на Apple Silicon; чистый Mac не проверен | Прототип сборки Ubuntu x86-64 через Docker и запуск проверены; последняя версия целиком не проверена | Не готово |

Инструкции: [сборка macOS](docs/BUILD.md), [сборка Ubuntu с Mac](scripts/linux-release/README.md). Модели и пространства хранятся отдельно от приложения.
