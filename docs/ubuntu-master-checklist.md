# Atlas: подготовка поддержки Ubuntu

Статус: план, 15.11.2026. Перенос и испытания на Ubuntu отложены по просьбе пользователя.

1. Зафиксировать проверенный исходный снимок macOS и определить разницу с последней проверенной Ubuntu-сборкой; обновить таблицу поддержки в README, отдельно отмечая непроверенные функции.
2. Проверить зависимости сборки из исходников, актуальность закреплённых версий и доступность сборки Ubuntu x86-64 из Docker на Mac. Пересобрать архив из зафиксированного снимка, не включать модели, ключи и пользовательские пространства.
3. На изолированных данных проверить запуск, сохранение, открытие и закрытие пространств, чтение и индексирование файлов; отдельно проверить флешку и защищённое пространство, перенос индексов между macOS и Linux и работу после отключения носителя.
4. Проверить agent CLI: установку, расположение сокета и файлов ключей, доступ по отдельным правам, поведение заблокированных пространств, чтение, добавление, изменение, удаление, загрузку и все режимы поиска. Проверить одновременную работу UI и нескольких агентов, очередь модели, отмену, отзыв прав и устойчивость после перезапуска.
5. Проверить журнал действий и отсутствие незащищённых копий содержимого защищённых пространств при экспорте, установке/снятии защиты и очистке истории. Проверить автоматическую очистку неудачных загрузок и восстановление после сбоев.
6. На Ubuntu x86-64 проверить CPU-модели, отсутствие настроек Apple Metal, ограничения памяти/CPU, установку без имеющихся моделей и работу приложения из пакета. На время тестов сохранять исходные данные пользователя и использовать тестовые пространства.
7. Выполнить независимое ревью различий платформ, повторить релевантные тесты, документировать реально проверенное и ограничения. Только после этого готовить выпуск Ubuntu; Windows остаётся отдельной экспериментальной веткой.

**Условие для слияния в master:** сначала реализовать и проверить актуальную функциональность из develop на Ubuntu, включая перечисленные выше сценарии; до этого изменения остаются в develop.
