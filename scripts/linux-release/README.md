# Сборка Atlas для Ubuntu x86-64 с Mac

Прототип: пакет полного приложения в виде архива `.tar.gz` для Ubuntu 26.04 x86-64. Сборка запускается на Mac внутри Docker с `--platform linux/amd64`. На Apple Silicon используется трансляция x86-64; продолжительность первой сборки пока не измерена. Это не универсальный пакет для всех Linux и не `.deb`.

## Запуск

Нужен запущенный Docker Desktop с поддержкой linux/amd64 и доступ к Ubuntu Snapshot, GitHub, npm и crates.io. После включения `Dockerfile` и скрипта в репозиторий:

```sh
./scripts/linux-release/build-linux.sh /путь/к/atlas /путь/для/результата/Atlas-linux-x86_64.tar.gz
```

Скрипт берёт только зафиксированное состояние HEAD, не включает незакоммиченные изменения и не заменяет существующий архив. Во время компиляции максимум две параллельные задачи; ограничение памяти для сборки настраивается в Docker Desktop. Пакет содержит `Atlas/bin/atlas` и каталог `Atlas/lib/Atlas/resources`. Распаковать архив на Ubuntu, при необходимости установить системные библиотеки GTK 3, WebKitGTK 4.1, OpenBLAS, OpenSSL и Zenity, затем запустить `Atlas/bin/atlas`. Передавать только архиву, которому доверяешь. Модели и данные в пакет не включаются: Atlas использует обычный каталог пользователя `~/.local/share/local.atlas.desktop`.

## Источники и ограничения

- Образ Ubuntu 26.04 amd64 закреплён по digest; пакеты сборки берутся из снимка Ubuntu от 3 ноября 2026. Первоначально сертификаты для доступа к снимку устанавливаются из обычного подписанного архива Ubuntu, затем устанавливаются пакеты из снимка. Доступность исторического снимка не гарантирована бессрочно.
- Исходники FAISS v1.15.1 и llama.cpp b12001 проверяются по полным хешам коммитов; PDFium 158.0.8125.0 — по SHA-256. Cargo и npm используют lock-файлы проекта. В `BUILD-INFO.txt` и `BUILD-PACKAGES.txt` фиксируются фактические версии.
- Для ускорения движка моделей включены SSE4.2, AVX, AVX2, BMI2, FMA и F16C: на проверенном Ryzen 5 7430U все они доступны; на старых x86-64 компьютерах их наличие нужно проверить. `-march=native` отключён, чтобы архитектура машины сборки не влияла на результат. Библиотеки llama ищутся рядом с программой, а не в каталоге сборки.
- Пакет содержит лицензии FAISS, llama.cpp и PDFium. Состав лицензий всех транзитивных Rust/npm-зависимостей отдельно не проверен; архив ещё не подготовлен для публичного распространения.
- Фиксация исходников и снимка пакетов облегчает повтор сборки, но побайтовая идентичность архивов не подтверждена. Первый полный прогон сборки и запуск полученного архива на Ubuntu ещё обязательны. GUI, поиск, флешка и защита пространств не проверяются самим Dockerfile.
